Yazar girişi

Bu sayfa sadece blog sahibi içindir. Giriş anahtarın yalnızca bu tarayıcıda saklanır.

Anahtarı nereden alırım?
  1. github.com/settings/personal-access-tokens/new sayfasını aç.
  2. Token name: AeroNotes · Expiration: istediğin süre.
  3. Repository access → Only select repositories → aeronotes.
  4. Permissions → Contents → Read and write.
  5. Generate token'a bas, çıkan anahtarı kopyalayıp buraya yapıştır.
