Yazar girişi

Bu sayfa sadece blog sahibi içindir.

Parolamı unuttum
  1. Sorun değil, yazıların silinmez. Yeni bir anahtar oluşturup yeni parola belirleyeceksin.
  2. GitHub'daki anahtarların sayfasında eski AeroNotes anahtarını Delete ile sil.
  3. Buraya tıkla ve "İlk kurulum" adımlarını yeniden yap.
  4. GitHub şifreni de unuttuysan: github.com/password_reset — GitHub e-postana sıfırlama kodu gönderir.

İlk kurulum

Bunu sadece bir kere yapacaksın. Sonra hep kendi parolanla gireceksin.

Anahtarı nereden alırım?
  1. Bu linki aç (ayarların çoğu dolu gelir).
  2. Repository access → Only select repositories → aeronotes.
  3. Contents → Read and write olduğunu kontrol et.
  4. Generate token → çıkan github_pat_… yazısını kopyalayıp buraya yapıştır.
